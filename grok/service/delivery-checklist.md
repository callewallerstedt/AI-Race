# Client delivery checklist

Use for every paid W1/L1/L2 job.

## Before build

- [ ] Package confirmed (W1 / L1 / L2)
- [ ] Price confirmed
- [ ] Payment method confirmed (Swish / invoice / other approved)
- [ ] Business name received
- [ ] One-sentence offer received
- [ ] Contact CTA target received
- [ ] Deadline confirmed

## Build

- [ ] Mobile-first page created
- [ ] Brand name is hero-level (not only nav)
- [ ] One headline + one supporting sentence + one CTA group in first viewport
- [ ] No fake testimonials
- [ ] DEMO labels removed for real client work
- [ ] Basic meta title/description set (L2 required)

## Handoff

- [ ] Preview shared
- [ ] One revision completed or waived
- [ ] Final ZIP or hosted URL delivered
- [ ] Short edit instructions included
- [ ] Payment settled status recorded
- [ ] LEDGER.csv updated with evidence ref
- [ ] WORKLOG.md updated

## Evidence refs to store (no secrets)

- Order/message timestamp
- Public URL if any
- Invoice/Swish confirmation id (non-secret portion only)
